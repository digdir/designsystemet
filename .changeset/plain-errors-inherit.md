**ErrorSummary**: Added `--dsc-errorsummary-color` for the text in the summary. Deprecated `--dsc-errorsummary-heading-color`, which now defaults to `--dsc-errorsummary-color`, and `--dsc-errorsummary-link-color`, which keeps the neutral text color until the next major version, where links use `--dsc-errorsummary-color`. Also deprecated the default styles for headings and list items inside the summary. Use `Heading` and `List` for these.
