**ErrorSummary**: Added `--dsc-errorsummary-color` for the text in the summary, which defaults to the danger text color. Headings and links in the summary now use this color too, so links change from the neutral text color to the danger text color. Deprecated `--dsc-errorsummary-heading-color` and `--dsc-errorsummary-link-color`, which now default to `currentcolor`. Also deprecated the default list item styles inside the summary. Use `List` for lists.
