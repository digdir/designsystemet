**CLI:** New `output` field for choosing what the CLI creates. It defaults to `["css"]`. Each output is saved in a default folder, which you can change with `dir`:
- `"css"`: CSS, in `designsystemet`
- `"types"`: type declarations, in `designsystemet`
- `"design-tokens"`: design tokens, in `designsystemet/design-tokens`
