**Suggestion:** `--dsc-suggestion-create-text` is now only the text before the typed value, for example `'Legg til'`. The typed value is added automatically, so `{value}` and `%s` are no longer replaced. If you have set this variable yourself, remove `{value}` or `%s` from it, otherwise it shows up as literal text. The default empty text is changed to "Ingen søketreff" / "No hits".
