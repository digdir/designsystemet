This package is used for resources related to the Figma UI kit, Designsystemet - Core UI Kit: https://www.figma.com/community/file/1322138390374166141

- [designsystemet.config.json](./designsystemet.config.json): the starter theme used in the UI kit
- [CHANGELOG.md](./CHANGELOG.md): what changed in each version of the UI kit

See [the Figma README](../README.md) for how versions work, how to document changes, and how to publish a new version.
