If you want to change values the configuration file doesn't support yet, you can edit the Design Tokens directly. The [Designsystemet plugin](/en/fundamentals/figma/plugin) can't import these changes into Figma, so you sync the Design Tokens with Figma using the Tokens Studio plugin instead.

This builds on [Build your theme](/en/fundamentals/start-here/own-theme), with your configuration file in a Git repository.

## How to set it up

1. Create the Design Tokens once: add `"design-tokens"` to `output` in the configuration file, and run the CLI in the folder with it.

```json
{
  "output": ["design-tokens"],
  "themes": {
    "theme": {
      "colors": {
        "primary": "#0062BA",
        "neutral": "#1E2B3C",
        "extra1": "#F45F63"
      },
      "borderRadius": 4
    }
  }
}
```

```bash
npx @digdir/designsystemet@latest
```

This creates the Design Tokens in a folder called `designsystemet/design-tokens`. This is where you make your changes to them.

2. Build the CSS from your Design Tokens, instead of creating the Design Tokens again from the configuration file. Change `output` to:

```json
"output": [
  { "type": "css", "tokensDir": "designsystemet/design-tokens" }
]
```

Run the CLI again. It builds the CSS from your Design Tokens, and leaves the Design Tokens as they are. Push the changes to your repository.

**Remember to run the CLI every time you change the Design Tokens.**

3. Install the plugin [Tokens Studio (figma.com)](https://www.figma.com/community/plugin/843461159747178978/Tokens-Studio-for-Figma-(Figma-Tokens)). This plugin enables synchronisation between Figma and code. You do *not* need a Pro licence.

<Image
  src='/img/fundamentals/start-here/own-theme/tokenstudio.png'
  alt='Screenshot of Figma showing where to find plugins'
  boxShadow={false}
/>

  - In the plugin, set up the connection to your Git repository. See Tokens Studio’s guide “[Sync your Design Tokens with code (tokens.studio)](https://docs.tokens.studio/token-storage/remote/#sync-providers)” which explains how to do this for different Git providers.
  - Remember to set the “Token storage location” to `designsystemet/design-tokens` (or whatever you have named your Design Tokens folder).

<Alert data-color="info">
You can change the Design Tokens in your repository, or in Tokens Studio and push them. Run the CLI afterwards to build the CSS from them.
</Alert>

4. In Tokens Studio, select the “Pull” icon to fetch the tokens into Figma.

<Image
  src='/img/fundamentals/start-here/own-theme/tokens-studio-pull-button.png'
  alt='Screenshot of Tokens Studio showing where to find the Pull button'
  boxShadow={false}
/>

Select `Styles & variables` and `Export styles & variables to Figma`.

<Image
  src='/img/fundamentals/start-here/own-theme/tokens-export.webp'
  alt='Screenshot of Tokens Studio showing where to find the Export button'
  boxShadow={false}
/>

Make sure you have these settings before clicking `Confirm`:

<Image
  src='/img/fundamentals/start-here/own-theme/tokens-export-options.webp'
  alt='Screenshot of Tokens Studio showing which settings to use when exporting tokens to Figma'
  boxShadow={false}
/>

Select `Themes`, `Select All`, and `Export to Figma`:

<Image
  src='/img/fundamentals/start-here/own-theme/tokens-export-themes-select.webp'
  alt='Screenshot of Tokens Studio showing that you must select Themes and then Select All'
  boxShadow={false}
/>

You should now see all components using your brand colours in Figma.

**Note:** Tokens Studio does not delete existing modes during export. After export, check the Theme and Color collections, and remove any default themes that may still remain from the Community file.

<Alert data-color="info">
When the Design Tokens are updated in code, you can easily fetch the new values into Figma by using the “Pull” button in Tokens Studio again.
</Alert>

## When you change your theme

Creating the Design Tokens again from the configuration file replaces your changes to them. To bring in changes from the Theme Builder, such as new colours, and keep your changes, you can split the configuration file in two and run a script between them that makes your changes to the Design Tokens again.

`create-tokens.json` creates the Design Tokens from your themes. `cleanDir` removes the Design Tokens of colours you have removed.

```json
{
  "output": [{ "type": "design-tokens", "cleanDir": true }],
  "themes": {
    // Your themes from the Theme Builder
  }
}
```

`build-tokens.json` builds the CSS from the Design Tokens. It doesn't need any themes, since it only uses the Design Tokens.

```json
{
  "output": [{ "type": "css", "tokensDir": "designsystemet/design-tokens" }]
}
```

Run them one after the other, with your script in between:

```bash
npx @digdir/designsystemet@latest --config create-tokens.json &&
node update-tokens.js &&
npx @digdir/designsystemet@latest --config build-tokens.json
```

`update-tokens.js` is your own script that makes your changes to the Design Tokens. If you don't have a script, you can make the changes again by hand, or restore them with Git, before you build the CSS.
