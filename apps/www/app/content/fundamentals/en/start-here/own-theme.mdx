Designsystemet is designed to be used with your own visual identity, including colours and other preferences. With the [Designsystemet Theme Builder](https://theme.designsystemet.no), you set up your theme in a configuration file. The same file is used in Figma, with the Designsystemet plugin, and in code, with the CLI, so design and code use the same values.

<Alert data-color="info">
We recommend that both a developer and a designer take part in the process when setting up your theme.
</Alert>

## How to get started:

1. Use the [Designsystemet Theme Builder](https://theme.designsystemet.no) to set up your theme. You can set up several themes in the same configuration file under **Edit themes**.

2. Click **Use theme**, and download or copy the configuration file. Save it as a `json` file, we recommend e.g. `designsystemet.config.json` or `<your-organization>.config.json`.

### In Figma

3. Fetch the component library from [Figma Community (figma.com)](https://www.figma.com/community/file/1322138390374166141/designsystemet-core-ui-kit) (Click “Open in Figma”) into your organisation that has at least a Pro licence. Note that this will be a copy of the component library without any connection to the main file.

4. In your copy, open the Designsystemet plugin. Upload the configuration file under **Upload config**, or paste it under **Or paste the config**, and click **Import**.

   The plugin creates the variables and styles for your themes, and you should now see all components using your brand colours.

   - Each theme, colour scheme and size is a mode in Figma, and how many modes a collection can have depends on your Figma plan.
   - The fonts in your theme must be available in Figma.
   - The plugin keeps variables, styles and modes it didn't create, such as the example themes from the Community file, and lists them after the import. Delete the ones you don't need.

### In code

5. Place `designsystemet.config.json` in your project, in the folder where you want the theme's files.

6. Make sure you have Node.js `22.12.0` or higher installed. Open a terminal in that folder, and run:

```bash
npx @digdir/designsystemet@latest
```

This generates CSS for your themes, directly from the configuration file, in a folder called `designsystemet`. You can change what is generated, and where, with the [`output`](/en/fundamentals/code/cli-config#output) field in the configuration file. See [Setup](/en/fundamentals/code/setup) for how to use the CSS in your code.

### When you change your theme

Update the configuration file in the Theme Builder: click **Import config** and paste your configuration file to continue where you left off. Then:

- **In Figma**, import the new configuration file with the plugin. It only changes what has changed, and components using the variables and styles stay connected.
- **In code**, replace `designsystemet.config.json` with the new file and run the command again.

### Icons in Figma
To get icons working in Figma, they need to be connected to a library stored in your organisation. See the guide ["Get icons working in Figma"](/en/fundamentals/theme/icons#get-icons-working-in-figma).

## Alternative: Design Tokens and Tokens Studio

If you've changed the Design Tokens in ways the configuration file can't describe, the plugin can't bring those changes into Figma. See [Sync Design Tokens with Tokens Studio](/en/fundamentals/figma/tokens-studio) for how to sync them with Figma instead.
