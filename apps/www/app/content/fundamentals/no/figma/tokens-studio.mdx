Hvis du vil konfigurere Designsystemet på måter config-filen ikke støtter ennå, kan du endre hva du vil i Designsystemet ved å redigere Design Tokens. [Designsystemet-pluginen](/no/fundamentals/figma/plugin) kan ikke importere de endringene til Figma, så da synkroniserer du Design Tokens med Figma med pluginen Tokens Studio i stedet.

Dette bygger på [Bygg ditt tema](/no/fundamentals/start-here/own-theme), med config-filen din i et Git repository.

## Slik setter du det opp

1. Lag Design Tokens én gang: legg til `"design-tokens"` i `output` i config-filen, og kjør CLI-et i mappen med den.

```json
{
  "output": ["design-tokens"],
  "themes": {
    "theme": {
      "colors": {
        "primary": "#0062BA",
        "neutral": "#1E2B3C",
        "extra1": "#F45F63"
      },
      "borderRadius": 4
    }
  }
}
```

```bash
npx @digdir/designsystemet@latest
```

Dette lager Design Tokens i en mappe som heter `designsystemet/design-tokens`. Det er her du gjør endringene dine i dem.

2. Bygg CSS-en fra Design Tokens dine, i stedet for å lage Design Tokens på nytt fra config-filen. Endre `output` til:

```json
"output": [
  { "type": "css", "tokensDir": "designsystemet/design-tokens" }
]
```

Kjør CLI-et på nytt. Det bygger CSS-en fra Design Tokens dine, og lar Design Tokens være som de er. Push endringene til ditt repo.

**Husk å kjøre CLI-et hver gang du endrer Design Tokens.**

3. Installer pluginen [Tokens Studio (figma.com)](https://www.figma.com/community/plugin/843461159747178978/Tokens-Studio-for-Figma-(Figma-Tokens)). Den sørger for kobling mellom Figma og kode. Du trenger *ikke* pro-lisens.

<Image
  src='/img/fundamentals/start-here/own-theme/tokenstudio.png'
  alt='Skjermbilde av Figma som vise hvor du finner plugins'
  boxShadow={false}
/>

  - I pluginen skal du nå sette opp kobling til ditt Git repo. Se Tokens Studio sin guide "[Sync your Design Tokens with code (tokens.studio)](https://docs.tokens.studio/token-storage/remote/#sync-providers)" som forklarer hvordan du gjør dette for ulike Git Providers.
  - Husk å sette "Token storage location" til `designsystemet/design-tokens` (eller det du har valgt å kalle mappen din med Design Tokens).

<Alert data-color="info">
Du kan endre Design Tokens i repoet ditt, eller i Tokens Studio og pushe dem. Kjør CLI-et etterpå for å bygge CSS-en fra dem.
</Alert>

Velg `Styles & variables` og `Export styles & variables to Figma`.

**Obs:** Token Studio sletter ikke eksisterende modes ved eksport. Etter eksport: kontroller collectionene Theme og Color, og fjern eventuelle standardtemaer som fortsatt ligger igjen fra community filen.

<Alert data-color="info">
Når Design Tokens oppdateres i koden, kan du enkelt hente de nye verdiene inn i Figma ved å bruke "Pull"-knappen i Tokens Studio igjen.
</Alert>

## Når du endrer temaet

Når du lager Design Tokens på nytt fra config-filen, blir endringene dine i dem erstattet. For å hente inn endringer fra Temabyggeren, som nye farger, og samtidig beholde endringene dine, kan du dele config-filen i to og kjøre et script mellom dem som gjør endringene dine i Design Tokens på nytt.

`create-tokens.json` lager Design Tokens fra temaene dine. `cleanDir` fjerner Design Tokens for farger du har fjernet.

```json
{
  "output": [{ "type": "design-tokens", "cleanDir": true }],
  "themes": {
    // Temaene dine fra Temabyggeren
  }
}
```

`build-tokens.json` bygger CSS-en fra Design Tokens. Den trenger ingen temaer, siden den bare bruker Design Tokens.

```json
{
  "output": [{ "type": "css", "tokensDir": "designsystemet/design-tokens" }]
}
```

Kjør dem etter hverandre, med scriptet ditt imellom:

```bash
npx @digdir/designsystemet@latest --config create-tokens.json &&
node update-tokens.js &&
npx @digdir/designsystemet@latest --config build-tokens.json
```

`update-tokens.js` er ditt eget script som gjør endringene dine i Design Tokens. Har du ikke et script, kan du gjøre endringene på nytt for hånd, eller hente dem tilbake med Git, før du bygger CSS-en.
