Hvis du har endret Design Tokens på måter config-filen ikke kan beskrive, kan ikke [Designsystemet-pluginen](/no/fundamentals/figma/plugin) hente de endringene inn i Figma. Da kan du i stedet lagre Design Tokens i repoet ditt og synkronisere dem med Figma med pluginen Tokens Studio.

Dette bygger på [Bygg ditt tema](/no/fundamentals/start-here/own-theme), med config-filen din i et Git repository.

## Slik setter du det opp

1. Lag Design Tokens én gang: legg til `"design-tokens"` i `output` i config-filen, og kjør CLI-et i mappen med den.

```json
{
  "output": ["design-tokens", "css", "types"],
  "themes": {
    "theme": {
      "colors": {
        "primary": "#0062BA",
        "neutral": "#1E2B3C",
        "extra1": "#F45F63"
      },
      "borderRadius": 4
    }
  }
}
```

```bash
npx @digdir/designsystemet@latest
```

Dette lagrer Design Tokens i en mappe som heter `designsystemet/design-tokens`. Det er her du gjør endringene dine i dem.

2. Bygg CSS-en og typene fra Design Tokens dine, i stedet for å lage Design Tokens på nytt fra config-filen. Endre `output` til:

```json
"output": [
  { "type": "css", "tokensDir": "designsystemet/design-tokens" },
  { "type": "types", "tokensDir": "designsystemet/design-tokens" }
]
```

Kjør CLI-et på nytt. Det bygger CSS-en og typene fra Design Tokens dine, og lar Design Tokens være som de er. Push endringene til ditt repo.

**Husk å kjøre CLI-et hver gang du endrer Design Tokens.**

3. Installer pluginen [Tokens Studio (figma.com)](https://www.figma.com/community/plugin/843461159747178978/Tokens-Studio-for-Figma-(Figma-Tokens)). Den sørger for kobling mellom Figma og kode. Du trenger *ikke* pro-lisens.

<Image
  src='/img/fundamentals/start-here/own-theme/tokenstudio.png'
  alt='Skjermbilde av Figma som vise hvor du finner plugins'
  boxShadow={false}
/>

  - I pluginen skal du nå sette opp kobling til ditt Git repo. Se Tokens Studio sin guide "[Sync your Design Tokens with code (tokens.studio)](https://docs.tokens.studio/token-storage/remote/#sync-providers)" som forklarer hvordan du gjør dette for ulike Git Providers.
  - Husk å sette "Token storage location" til `designsystemet/design-tokens` (eller det du har valgt å kalle mappen din med Design Tokens).

<Alert data-color="info">
Du kan endre Design Tokens i repoet ditt, eller i Tokens Studio og pushe dem. Kjør CLI-et etterpå for å bygge CSS-en fra dem.
</Alert>

Velg `Styles & variables` og `Export styles & variables to Figma`.

**Obs:** Token Studio sletter ikke eksisterende modes ved eksport. Etter eksport: kontroller collectionene Theme og Color, og fjern eventuelle standardtemaer som fortsatt ligger igjen fra community filen.

<Alert data-color="info">
Når Design Tokens oppdateres i koden, kan du enkelt hente de nye verdiene inn i Figma ved å bruke "Pull"-knappen i Tokens Studio igjen.
</Alert>

## Når du endrer temaet

Når du lager Design Tokens på nytt fra config-filen, blir endringene dine i dem erstattet. For å hente inn endringer fra Temabyggeren, som nye farger, legger du `"design-tokens"` tilbake i `output` og kjører CLI-et. Deretter gjør du endringene dine i Design Tokens på nytt, for eksempel ved å gjenopprette dem med Git, og endrer `output` tilbake som i steg 2.
