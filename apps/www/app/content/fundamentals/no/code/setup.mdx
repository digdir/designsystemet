Her viser vi hvordan du legger til Designsystemet i prosjektet ditt.
Eksemplene bruker npm og et byggeverktøy som Vite.

## 1. Installer pakkene

CSS-pakken gir deg utseendet.
Web- og React-pakkene gir noen komponenter funksjonene sine.
Velg HTML for vanlig HTML eller rammeverk som Vue, Angular og Svelte, eller velg React.

## 4. Bruk komponentene

Her er et felt og en knapp du kan starte med:

<Tabs defaultValue="html" data-wide-content>
  <Tabs.List>
  <Tabs.Tab value="html">HTML</Tabs.Tab>
  <Tabs.Tab value="react">React</Tabs.Tab>
  </Tabs.List>
  <Tabs.Panel value="html">

**HTML og andre rammeverk**

```html
<div data-color-scheme="auto" data-size="md">
  <ds-field class="ds-field">
    <label class="ds-label">Navn</label>
    <input class="ds-input" type="text" />
  </ds-field>
  <button class="ds-button" data-variant="secondary" type="button">
    Fortsett
  </button>
</div>
```
  </Tabs.Panel>
  <Tabs.Panel value="react">

**React**

```tsx
import { Button, Field, Input, Label } from '@digdir/designsystemet-react';

export function Example() {
  return (
    <div data-color-scheme='auto' data-size='md'>
      <Field>
        <Label>Navn</Label>
        <Input type='text' />
      </Field>
      <Button variant='secondary'>Fortsett</Button>
    </div>
  );
}
```
  </Tabs.Panel>
</Tabs>

Du kan sette farger og størrelser på en komponent eller et element rundt den:

- `data-color-scheme="auto"` følger brukerens preferanse. Du kan også velge `light` eller `dark`.
- `data-size="md"` setter størrelsen. Du kan også velge `sm` eller `lg`.
- `data-color="accent"` setter fargen. Hvilke farger du kan velge, avhenger av temaet.

## TypeScript

Typene følger med pakkene.
For å få støtte for webkomponenter eller React-attributter og temafarger, legg til disse oppføringene i `compilerOptions.types` i `tsconfig.json`.
Behold oppføringene du allerede har.

## Font

Standardtemaet bruker [Inter](https://github.com/rsms/inter).
Du kan bruke en annen font i ditt eget tema.
Ta med fontvektene `400`, `500` og `600`.

### Tekstskalering som følger systeminnstillinger

Legg dette i `<head>` for å la nettlesere som støtter det [følge brukerens tekststørrelse](https://www.joshtumath.uk/posts/2026-07-02-lets-fix-the-webs-text-size/):

```html
<meta name="text-scale" content="scale">
```


### Legg til Inter fonten (valgfritt)

For å laste Inter legger du dette i `<head>`:

```html
<link
  rel="stylesheet"
  href="https://altinncdn.no/fonts/inter/v4.1/inter.css"
  integrity="sha384-OcHzc/By/OPw9uJREawUCjP2inbOGKtKb4A/I2iXxmknUfog2H8Adx71tWVZRscD"
  crossorigin="anonymous"
/>
```

### Bruk fonten

Legg dette i hovedfilen for CSS for å bruke fonten fra temaet.
`font-feature-settings` gir liten `l` en hale, så den blir lettere å skille fra stor `I`.

```css
body {
  font-family: var(--ds-font-family), sans-serif;
  font-feature-settings: 'cv05' 1; /* Enable lowercase l with tail */
}
```

## Testing

Vi tester med JSDOM, HappyDOM og ekte nettlesere.
JSDOM og HappyDOM støtter ikke alt en nettleser gjør, så testene dine kan trenge tilpasning.

<Details>
<Details.Summary>HappyDOM-oppsett</Details.Summary>

Legg dette i testoppsettet hvis HappyDOM ikke kjenner igjen `HTMLDocument` som `Document`:

```ts
// Polyfill missing HTMLDocument to Document inheritance in HappyDOM
if (
  typeof HTMLDocument !== 'undefined' &&
  typeof Document !== 'undefined' &&
  HTMLDocument.prototype !== Document.prototype &&
  !(Document.prototype instanceof HTMLDocument) &&
  !(HTMLDocument.prototype instanceof Document)
) {
  Object.setPrototypeOf(HTMLDocument.prototype, Document.prototype);
}
```
</Details>

<Details>
<Details.Summary>JSDOM-oppsett</Details.Summary>

Hvis dialogtestene feiler fordi JSDOM mangler `show`, `showModal` eller `close`, kan du legge til dette i testoppsettet:

```ts
// Minimal test mocks, not browser-equivalent dialog behaviour.
if (typeof HTMLDialogElement.prototype.show !== 'function') {
  HTMLDialogElement.prototype.show = function () {
    this.open = true;
  };
}

if (typeof HTMLDialogElement.prototype.showModal !== 'function') {
  HTMLDialogElement.prototype.showModal = function () {
    this.open = true;
  };
}

if (typeof HTMLDialogElement.prototype.close !== 'function') {
  HTMLDialogElement.prototype.close = function (returnValue?: string) {
    this.open = false;
    if (returnValue !== undefined) this.returnValue = returnValue;
    this.dispatchEvent(new Event('close'));
  };
}
```
</Details>

Bruk en ekte nettleser for å sjekke tastaturnavigasjon, fokus, dialoger og popovers.
