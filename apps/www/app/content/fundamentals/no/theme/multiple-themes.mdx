Det er mogleg å ha fleire tema i same prosjekt dersom du bruker ei [config-fil](/no/fundamentals/code/cli-config).
Under går vi gjennom to måtar å gjere det på.

**Denne sida føreset at du har lese "[Bygg ditt tema](/no/fundamentals/start-here/own-theme)".**

## Same fargenamn

Dersom du har to tema som skal bytast mellom i eitt og same grensesnitt, må du bruke same fargenamn i begge tema.
Då kan du legge begge inn i éi config-fil, som genererer to CSS-filer, éi per tema.

Til dømes:

```json
{
  "themes": {
    "some-org": {
      "colors": {
        "dominant": "#0062BA",
        "first": "#F45F63",
        "second": "#E5AA20",
        "neutral": "#303030"
      }
    },
    "other-org": {
      "colors": {
        "dominant": "#ffaaaa",
        "first": "#abcdef",
        "second": "#123456",
        "neutral": "#c05030"
      }
    }
  }
}
```

Du kan validere config-fila i temabyggaren. Klikk **Importer config** og lim inn config-fila.

## Ulike fargenamn

Dersom temaa har ulike fargenamn, kan dei ikkje liggje i same config-fil. CLI-et godtek det ikkje, og Figma kan ikkje byte mellom dei med modes på grunn av avgrensingar i korleis Figma handterer modes.
I dette tilfellet må du lage éi config-fil for kvart tema, og køyre kommandoen éin gong for kvar config-fil.

Det er vanleg å måtte gjere det slik dersom du har eit repository som samlar alle temaa for fleire merkevarer.

`some-org.config.json`:

```json
{
  "output": [{ "type": "css", "dir": "./some-org-css" }],
  "themes": {
    "some-org": {
      "colors": {
        "dominant": "#0062BA",
        "first": "#F45F63",
        "second": "#E5AA20",
        "neutral": "#303030"
      }
    }
  }
}
```

`other-org.config.json`:

```json
{
  "output": [{ "type": "css", "dir": "./other-org-css" }],
  "themes": {
    "other-org": {
      "colors": {
        "accent": "#0062BA",
        "brand1": "#F45F63",
        "brand2": "#E5AA20",
        "neutral": "#303030"
      }
    }
  }
}
```

Køyr dei etter kvarandre:

```bash
npx @digdir/designsystemet@latest --config some-org.config.json &&
npx @digdir/designsystemet@latest --config other-org.config.json
```

<Alert data-color="info">
Legg merke til at vi har ulike `output`-mapper i dei to config-filene, slik at CSS-en for kvart tema blir lagd i si eiga mappe.
</Alert>
