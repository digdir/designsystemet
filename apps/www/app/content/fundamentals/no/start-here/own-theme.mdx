Designsystemet er laget for å kunne brukes sammen med din egen visuelle profil - inkludert farger og andre preferanser. Med [Designsystemets Temabygger](https://theme.designsystemet.no) setter du opp temaet ditt i en config-fil. Den samme filen brukes i Figma, med Designsystemet-pluginen, og i kode, med CLI-et, så design og kode bruker de samme verdiene.

<Alert data-color="info">
Vi anbefaler at både utvikler og designer er med i prosessen når dere setter opp deres eget tema.
</Alert>


## Slik går du frem:

1. Bruk [Designsystemets Temabygger](https://theme.designsystemet.no) til å sette opp temaet ditt, eller bruk eksempelet under som utgangspunkt. Du kan sette opp flere temaer i den samme config-filen under **Rediger temaer**.

2. Klikk **Ta i bruk tema**, og last ned eller kopier config-filen. Lagre den som en `json`-fil, vi anbefaler f.eks. `designsystemet.config.json` eller `<din-organisasjon>.config.json`.

```json
{
  "themes": {
    "theme": {
      "colors": {
        "primary": "#0062BA",
        "neutral": "#1E2B3C",
        "extra1": "#F45F63"
      },
      "borderRadius": 4
    }
  }
}
```

### I Figma

3. Hent komponentbiblioteket fra [Figma Community (figma.com)](https://www.figma.com/community/file/1322138390374166141/designsystemet-core-ui-kit) (Trykk "Open in Figma") til din organisasjon som har minimum pro-lisens. Merk at dette blir en kopi av komponentbiblioteket uten noen kobling mot hovedfilen.

4. Åpne Designsystemet-pluginen i kopien din. Last opp config-filen under **Upload config**, eller lim den inn under **Or paste the config**, og klikk **Import**.

   Pluginen lager variablene og stilene for temaene dine, og nå skal du se alle komponentene med dine egne profilfarger.

   - Hvert tema, hver fargemodus og hver størrelse blir en mode i Figma, og hvor mange modes en collection kan ha, avhenger av Figma-abonnementet ditt.
   - Fontene i temaet ditt må være tilgjengelige i Figma.
   - Pluginen beholder variabler, stiler og modes den ikke har laget selv, som eksempeltemaene fra Community-filen, og lister dem opp etter importen. Slett de du ikke trenger.

### I kode

5. Finn et Git repository du kan lagre temaet ditt i. Legg `designsystemet.config.json`-fila i roten av repoet.

6. Pass på at du har Node.js installert, versjon 20 eller høyere. Åpne en terminal i repoet, og kjør:

```bash
npx @digdir/designsystemet@latest
```

Dette lager CSS og typedeklarasjoner for temaene dine, direkte fra config-filen, i en mappe som heter `designsystemet-theme`. Du kan endre hva som lages, og hvor, med [`output`](/no/fundamentals/code/cli-config#output)-feltet i config-filen. Se [Oppsett](/no/fundamentals/code/setup) for hvordan du bruker CSS-en i koden.

### Når du endrer temaet

Oppdater config-filen i Temabyggeren: klikk **Importer config** og lim inn config-filen din for å fortsette der du slapp. Deretter:

- I Figma importerer du den nye config-filen med pluginen. Den endrer bare det som er endret, og komponenter som bruker variablene og stilene, forblir koblet.
- I koden bytter du ut `designsystemet.config.json` med den nye filen og kjører kommandoen på nytt.

### Ikoner i Figma
For å få ikoner til å fungere i Figma, må de kobles til et bibliotek som er lagret på deres organisasjon. Se guiden ["Få ikoner til å fungere i Figma"](/no/fundamentals/theme/icons#få-ikoner-til-å-fungere-i-figma).

## Alternativ: Design Tokens og Tokens Studio

Hvis du har endret Design Tokens på måter config-filen ikke kan beskrive, kan ikke pluginen hente de endringene inn i Figma. Da kan du i stedet lagre Design Tokens i repoet ditt og synkronisere dem med Figma med pluginen Tokens Studio.

1. Legg til `"design-tokens"` i `output` i config-filen:

```json
{
  "output": ["design-tokens", "css", "types"],
  "themes": {
    "theme": {
      "colors": {
        "primary": "#0062BA",
        "neutral": "#1E2B3C",
        "extra1": "#F45F63"
      },
      "borderRadius": 4
    }
  }
}
```

2. Kjør kommandoen på nytt:

```bash
npx @digdir/designsystemet@latest
```

Dette lagrer Design Tokens i en mappe som heter `design-tokens`, og bygger CSS-en og typene fra dem. Push endringene til ditt repo.

**Husk at du må kjøre denne kommandoen hver gang du gjør endringer i config-filen.** Behold `output`-feltet når du bytter ut config-filen med en ny fra Temabyggeren.

3. Installer pluginen [Tokens Studio (figma.com)](https://www.figma.com/community/plugin/843461159747178978/Tokens-Studio-for-Figma-(Figma-Tokens)). Den sørger for kobling mellom Figma og kode. Du trenger *ikke* pro-lisens.

<Image
  src='/img/fundamentals/start-here/own-theme/tokenstudio.png'
  alt='Skjermbilde av Figma som vise hvor du finner plugins'
  boxShadow={false}
/>

  - I pluginen skal du nå sette opp kobling til ditt Git repo. Se Tokens Studio sin guide "[Sync your Design Tokens with code (tokens.studio)](https://docs.tokens.studio/token-storage/remote/#sync-providers)" som forklarer hvordan du gjør dette for ulike Git Providers.
  - Husk å sette "Token storage location" til `design-tokens` (eller det du har valgt å kalle mappen din med Design Tokens).

<Alert data-color="info">
Vi anbefaler å *ikke* pushe endringer i Design Tokens via Tokens Studio, da dette kan føre til at du mister overstyringene dine når du oppdaterer.
</Alert>

4. I Tokens Studio velg "Pull"-ikonet for å hente tokenene inn i Figma.

/>

Velg `Styles & variables` og `Export styles & variables to Figma`.

<Image
  src='/img/fundamentals/start-here/own-theme/tokens-export.webp'
  alt='Skjermbilde av Tokens Studio og hvor du finner export knappen'

/>

Pass på at du har disse innstillingene før du trykker `Confirm`:

<Image
  src='/img/fundamentals/start-here/own-theme/tokens-export-options.webp'
  alt='Skjermbilde av Tokens Studio og hvilke innstillinger du skal bruke når du eksporterer tokens til Figma'
  boxShadow={false}
/>

Velg `Themes`, `Select All` og `Export to Figma`:

<Image
  src='/img/fundamentals/start-here/own-theme/tokens-export-themes-select.webp'
  alt='Skjermbilde av Tokens Studio som viser at du må velge Themes og deretter Select All'
  boxShadow={false}
/>

Nå skal du se alle komponentene med dine egne profilfarger i Figma.

**Obs:** Token Studio sletter ikke eksisterende modes ved eksport. Etter eksport: kontroller collectionene Theme og Color, og fjern eventuelle standardtemaer som fortsatt ligger igjen fra community filen.

<Alert data-color="info">
Når Design Tokens oppdateres i koden, kan du enkelt hente de nye verdiene inn i Figma ved å bruke "Pull"-knappen i Tokens Studio igjen.
</Alert>
