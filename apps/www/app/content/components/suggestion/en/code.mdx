## Usage
Suggestion is based on [open-ui's combobox pattern (open-ui.org)](https://open-ui.org/components/combobox.explainer/) and uses [u-combobox from u-elements (github.io)](https://u-elements.github.io/u-elements/elements/u-combobox) to provide core combobox functionality.

Use the class `ds-suggestion` on the custom element `<ds-suggestion>`.
Add `<input class="ds-input" />` and `<u-datalist>` with `<u-option>` children to get a working suggestion.

```html
<ds-suggestion class="ds-suggestion">
  <input class="ds-input" />
  <u-datalist>
    <u-option label="Sogndal" value="Sogndal">Sogndal</u-option>
    <u-option label="Oslo" value="Oslo">Oslo</u-option>
    <u-option label="Brønnøysund" value="Brønnøysund">Brønnøysund</u-option>
  </u-datalist>
</ds-suggestion>
```

For a valid form control, we recommend using `<ds-suggestion>` inside `<ds-field>` together with a `<label>`.

```html
<ds-field>
  <label class="ds-label">Suggestion</label>
  <ds-suggestion class="ds-suggestion">
    <input class="ds-input" />
    <button type="reset" aria-label="Clear" />
    <u-datalist>
      <u-option label="Sogndal" value="Sogndal">Sogndal</u-option>
      <u-option label="Oslo" value="Oslo">Oslo</u-option>
      <u-option label="Brønnøysund" value="Brønnøysund">Brønnøysund</u-option>
    </u-datalist>
  </ds-suggestion>
</ds-field>
```

## CSS variables and data attributes

Sizes are controlled with [data-size](/en/fundamentals/code/sizes) and colors with [data-color](/en/fundamentals/code/colors).
The component will inherit from the closest parent where these are set.

Suggestion uses elements from `u-elements` and therefore supports many of the same custom elements, data attributes, and CSS variables.
You can read more about how to use these in the [u-elements `u-combobox` documentation](https://u-elements.github.io/u-elements/elements/u-combobox#attributes-and-props).

## Texts and translations

All texts in Suggestion are set with CSS variables, including the texts that are only read by screen readers. Norwegian (`lang="no"`, `lang="nb"` or `lang="nn"`) and English (`lang="en"`) are built in, and Suggestion uses the closest `lang` attribute to choose between them.

| CSS variable | Used for | English default |
| --- | --- | --- |
| `--dsc-suggestion-empty-text` | Text on an empty `data-empty` option | `'No hits'` |
| `--dsc-suggestion-create-text` | Text before the typed value on the create option with `data-creatable` | `'Add'` |
| `--dsc-suggestion-sr-clear` | Label for the clear button | `'Clear text'` |
| `--dsc-suggestion-sr-toggle` | Label for the toggle button | `'Suggestions'` |
| `--dsc-suggestion-sr-singular` | Number of hits, where `%d` is the number | `'%d suggestion'` |
| `--dsc-suggestion-sr-plural` | Number of hits, where `%d` is the number | `'%d suggestions'` |
| `--dsc-suggestion-sr-added` | Announced when an item is selected | `'Added'` |
| `--dsc-suggestion-sr-removed` | Announced when an item is removed | `'Removed'` |
| `--dsc-suggestion-sr-remove` | Hint on selected items | `'Press to remove'` |
| `--dsc-suggestion-sr-items` | Label for the selected items | `'Selected'` |
| `--dsc-suggestion-sr-empty` | Announced when no items are selected | `'None selected'` |
| `--dsc-suggestion-sr-found` | Hint about selected items, where `%d` is the number | `'Navigate left to find %d selected'` |
| `--dsc-suggestion-sr-of` | Between position and total, as in "1 of 3" | `'of'` |
| `--dsc-suggestion-sr-invalid` | Announced when the value is invalid | `'Invalid value'` |

To change a text, set the CSS variable on the suggestion itself:

```html
<ds-suggestion class="ds-suggestion" style="--dsc-suggestion-sr-plural: '%d results'">
```

To add another language, add a rule for that language. Note that your rule must be more specific than `.ds-suggestion:lang(en)` if you want to override one of the built-in languages:

```css
.ds-suggestion:lang(sv) {
  --dsc-suggestion-empty-text: 'Inga träffar';
  --dsc-suggestion-sr-clear: 'Rensa text';
  /* ...and the rest of the variables */
}
```

The texts were previously set with `data-sr-*` attributes. These attributes are no longer read, so use the CSS variables instead.

### Controlled multiple choice example

If you need to control which options are selected, render the selected items as `<data>` elements inside `Suggestion`, and update your state in `oncomboboxbeforeselect`. The `suggestion` helper converts your state to `{ label, value }` items, applies the event to your state, and renders each item:

```tsx
import { EXPERIMENTAL_Suggestion as Suggestion, suggestion } from '@digdir/designsystemet-react'

const [selected, setSelected] = useState(suggestion(['Oslo']));
const handleSelect: SuggestionProps['oncomboboxbeforeselect'] = (e) =>
  setSelected(suggestion(selected, e));

<Suggestion
  data-multiple
  oncomboboxbeforeselect={handleSelect}
>
  {suggestion(selected, ({ label, value }) => (
    <data key={value} value={value}>{label}</data>
  ))}
  <Suggestion.Input />
  ...
</Suggestion>
```
