## Bruk
Suggestion baserer seg på [open-ui sitt combobox mønster (open-ui.org)](https://open-ui.org/components/combobox.explainer/) og bruker [u-combobox fra u-elements (github.io)](https://u-elements.github.io/u-elements/elements/u-combobox) for å oppfylle grunnleggende funksjonalitet fra combobox mønsteret.

Bruk klassen `ds-suggestion` på custom elementet `<ds-suggestion>`.
Legg til `<input class="ds-input" />` og `<u-datalist>` med `<u-option>` som barn for å få en fungerende suggestion.

```html
<ds-suggestion class="ds-suggestion">
  <input class="ds-input"  />
  <u-datalist>
    <u-option label="Sogndal" value="Sogndal">Sogndal</u-option>
    <u-option label="Oslo" value="Oslo">Oslo</u-option>
    <u-option label="Brønnøysund" value="Brønnøysund">Brønnøysund</u-option>
  </u-datalist>
</ds-suggestion>
```

For et gyldig skjemaelement anbefaler vi å bruke `<ds-suggestion>` i `<ds-field>` sammen med en `<label>`.

```html
<ds-field>
  <label class="ds-label" >Checkbox</label>
  <ds-suggestion class="ds-suggestion">
    <input class="ds-input"  />
    <button type="reset" aria-label="Tøm"/>
    <u-datalist>
      <u-option label="Sogndal" value="Sogndal">Sogndal</u-option>
      <u-option label="Oslo" value="Oslo">Oslo</u-option>
      <u-option label="Brønnøysund" value="Brønnøysund">Brønnøysund</u-option>
    </u-datalist>
  </ds-suggestion>
</ds-field>
```

## Tekster og oversettelser

Alle tekster i Suggestion settes med CSS-variabler, også tekstene som bare leses opp av skjermleser. Norsk (`lang="no"`, `lang="nb"` eller `lang="nn"`) og engelsk (`lang="en"`) er innebygd, og Suggestion bruker nærmeste `lang`-attributt for å velge mellom dem.

| CSS-variabel | Brukes til | Norsk standard |
| --- | --- | --- |
| `--dsc-suggestion-empty-text` | Tekst på et tomt `data-empty`-alternativ | `'Ingen søketreff'` |
| `--dsc-suggestion-create-text` | Tekst foran den skrevne verdien på alternativet for å legge til, med `data-creatable` | `'Legg til'` |
| `--dsc-suggestion-sr-clear` | Ledetekst for tøm-knappen | `'Fjern tekst'` |
| `--dsc-suggestion-sr-toggle` | Ledetekst for knappen som åpner og lukker listen | `'Forslag'` |
| `--dsc-suggestion-sr-singular` | Antall treff, der `%d` er antallet | `'%d forslag'` |
| `--dsc-suggestion-sr-plural` | Antall treff, der `%d` er antallet | `'%d forslag'` |
| `--dsc-suggestion-sr-added` | Leses opp når et element blir valgt | `'La til'` |
| `--dsc-suggestion-sr-removed` | Leses opp når et element blir fjernet | `'Fjernet'` |
| `--dsc-suggestion-sr-remove` | Hint på valgte elementer | `'Trykk for å fjerne'` |
| `--dsc-suggestion-sr-items` | Ledetekst for de valgte elementene | `'Valgte'` |
| `--dsc-suggestion-sr-empty` | Leses opp når ingen elementer er valgt | `'Ingen valgte'` |
| `--dsc-suggestion-sr-found` | Hint om valgte elementer, der `%d` er antallet | `'Naviger til venstre for å finne %d valgte'` |
| `--dsc-suggestion-sr-of` | Mellom posisjon og totalt antall, som i "1 av 3" | `'av'` |
| `--dsc-suggestion-sr-invalid` | Leses opp når verdien er ugyldig | `'Ugyldig valg'` |

For å endre en tekst, sett CSS-variabelen på selve suggestion:

```html
<ds-suggestion class="ds-suggestion" style="--dsc-suggestion-sr-plural: '%d resultater'">
```

For å legge til et annet språk, legg til en regel for det språket. Merk at regelen din må være mer spesifikk enn `.ds-suggestion:lang(no)` hvis du vil overstyre et av de innebygde språkene:

```css
.ds-suggestion:lang(sv) {
  --dsc-suggestion-empty-text: 'Inga träffar';
  --dsc-suggestion-sr-clear: 'Rensa text';
  /* ...og resten av variablene */
}
```

Tidligere ble tekstene satt med `data-sr-*`-attributter. Disse attributtene leses ikke lenger, så bruk CSS-variablene i stedet.

### Legge til nye alternativer

Med `data-creatable` på suggestion kan en bruker opprette nye valgte alternativer ved å skrive inn tekst i input og trykke <kbd>Enter</kbd>.

<Story story='Creatable' />

### Tøm valget

Legg til en knapp med `type="reset"` for å la brukeren tømme valget. Knappen får ledetekst fra `--dsc-suggestion-sr-clear`.

<Story story='Preview' />

### Åpne og lukk liste

Legg til en knapp med `type="button" aria-expanded="false"` for å la brukeren åpne og lukke listen. Knappen får ledetekst fra `--dsc-suggestion-sr-toggle`.

### Eksempel på kontrollert flervalg

Har du behov for å kontrollere hvilke alternativer som er valgt, rendrer du de valgte elementene som `<data>` inne i `Suggestion`, og oppdaterer state i `oncomboboxbeforeselect`. Hjelpefunksjonen `suggestion` gjør om state til `{ label, value }`-elementer, bruker eventen på state, og rendrer hvert element:

```tsx
import { EXPERIMENTAL_Suggestion as Suggestion, suggestion } from '@digdir/designsystemet-react'

const [selected, setSelected] = useState(suggestion(['Oslo']));
const handleSelect: SuggestionProps['oncomboboxbeforeselect'] = (e) =>
  setSelected(suggestion(selected, e));

<Suggestion
  data-multiple
  oncomboboxbeforeselect={handleSelect}
>
  {suggestion(selected, ({ label, value }) => (
    <data key={value} value={value}>{label}</data>
  ))}
  <Suggestion.Input />
  ...
</Suggestion>
```
