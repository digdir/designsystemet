## Usage

The class name `ds-error-summary` is used on the `<ds-error-summary>` element.
The web component handles focus when it becomes visible and `aria-labelledby` automatically.

We add a `<ul class="ds-list">` after the heading which contains a list of errors.
Each error is a `<li>` with a link (`<a>`) that has the class `ds-link` and an `href` to the relevant field with the error.

## CSS variables and data attributes

Sizes are controlled with [data-size](/en/fundamentals/code/sizes) and colors with [data-color](/en/fundamentals/code/colors). The component will inherit from the closest parent where these are set.

## React

Use `Heading`, `List` and `Link` inside `ErrorSummary`:
- `Heading` defines the heading. Use level 2–6, since `ErrorSummary` uses the first `h2`–`h6` as its accessible name.
- `List.Unordered` contains the list of errors, with one `List.Item` per error.
- Each error has a `Link` with an `href` to the unique identifier for a form field, so that the user can navigate to the correct place in the form.

```tsx
import { ErrorSummary, Heading, Link, List } from '@digdir/designsystemet-react';

<ErrorSummary>
  <Heading>Heading</Heading>
  <List.Unordered>
    <List.Item>
      <Link href='#some-field-id'>Item</Link>
    </List.Item>
  </List.Unordered>
</ErrorSummary>
```

The subcomponents `ErrorSummary.Heading`, `ErrorSummary.List`, `ErrorSummary.Item` and `ErrorSummary.Link` are still available, and render the same components.
