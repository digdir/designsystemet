## Usage

The class name `ds-error-summary` is used on a `<fieldset>` element.
Focus is automatically moved to the error summary when it becomes visible.

Start with a `<legend>`, which becomes the accessible name of the error summary.
You can use `aria-label` or `aria-labelledby` instead, but the error summary must have an accessible name.
We add a `<ul class="ds-list">` after the legend which contains a list of errors.
Each error is a `<li>` with a link (`<a>`) that has the class `ds-link` and an `href` to the relevant field with the error.

## React

`ErrorSummary` renders a `<fieldset>`. Use `ErrorSummary.Heading`, `List` and `Link` inside it:
- `ErrorSummary.Heading` renders a `<legend>`, and becomes the accessible name of `ErrorSummary`.
- `List.Unordered` contains the list of errors, with one `List.Item` per error.
- Each error has a `Link` with an `href` to the unique identifier for a form field, so that the user can navigate to the correct place in the form.

```tsx
import { ErrorSummary, Link, List } from '@digdir/designsystemet-react';

<ErrorSummary>
  <ErrorSummary.Heading>Heading</ErrorSummary.Heading>
  <List.Unordered>
    <List.Item>
      <Link href='#some-field-id'>Item</Link>
    </List.Item>
  </List.Unordered>
</ErrorSummary>
```

The subcomponents `ErrorSummary.List`, `ErrorSummary.Item` and `ErrorSummary.Link` are still available, and render `List.Unordered`, `List.Item` and `Link` respectively.
