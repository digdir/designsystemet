## Usage

Use the class name `ds-validation-message` to style a validation message.


## Form fields and status

A validation message will automatically be connected to a form field when it has the attribute `data-field="validation"` and is inside a `<ds-field>`.
The form element automatically gets `aria-invalid="true"` when a validation message is visible in the default color `danger`.

<Alert>
**Note:** Use the `hidden` attribute or add/remove the validation message element, rather than hiding/showing with CSS class names or inline styling. This ensures `<ds-field>` can correctly convey the visibility of the validation message to assistive technologies.
</Alert>


## CSS variables and data attributes

Sizes are controlled with [data-size](/en/fundamentals/code/sizes) and colors with [data-color](/en/fundamentals/code/colors). The component will inherit from the closest parent where these are set.
