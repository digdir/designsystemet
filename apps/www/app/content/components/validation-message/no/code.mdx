## Bruk

Bruk klassenavnet `ds-validation-message` for å style en validation message.

## CSS variabler og data-attributter

Størrelser styres med [data-size](/no/fundamentals/code/sizes) og farger med [data-color](/no/fundamentals/code/colors). Komponenten vil arve nærmeste forelder med disse satt.

## React

```tsx
import { ValidationMessage } from '@digdir/designsystemet-react';

<ValidationMessage>Dette er en valideringsmelding.</ValidationMessage>
```

Komponenten setter alltid `data-field="validation"`, som vil gi `aria-invalid="true"` på tilhørende skjemafelt i `<ds-field>`.
For å unngå dette kan du sette `data-field={null}` på `<ValidationMessage>`.
