## Bruk

Bruk klassenavnet `ds-suggestion` på en `<ds-suggestion>` rundt `<input>`.
Vil du ha en tøm-knapp, legger du til en `<button type="reset">` etter `<input>`. Denne vises og skjules automatisk basert på verdien i input.

Du kan endre `variant` på button for å tilpasse visningen.
Forstørrelsesglass-ikonet vises når `input` har `type="search"`, og skjules når `input` har `type="text"`.

## React

`Search` er avviklet og blir fjernet i neste hovedversjon. Bruk `Input` med `type="search"` i en `Field` i stedet, eller `Suggestion` hvis du trenger en tøm-knapp.

```tsx
import {
  Button,
  EXPERIMENTAL_Suggestion as Suggestion,
  Field,
  Input,
  Label,
} from '@digdir/designsystemet-react';

// Søkefelt
<Field>
  <Label>Søk</Label>
  <Input type="search" />
</Field>

// Med tøm-knapp og søkeknapp
<Suggestion>
  <Suggestion.Input type="search" aria-label="Søk" />
  <Suggestion.Clear />
  <Button type="submit">Søk</Button>
</Suggestion>
```
