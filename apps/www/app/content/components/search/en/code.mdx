## Usage

Use the class name `ds-suggestion` on a `<ds-suggestion>` around `<input>`.
If you want a clear button, add a `<button type="reset">` after the `<input>`. It is automatically shown and hidden based on the input's value.

You can change the `variant` on the button to adjust its appearance.
The magnifying icon is shown when `input` has `type="search"`, and hidden when `input` has `type="text"`.

## CSS variables and data attributes

Sizes are controlled with [data-size](/en/fundamentals/code/sizes) and colors with [data-color](/en/fundamentals/code/colors). The component will inherit from the closest parent where these are set.

## React

`Search` is deprecated and will be removed in the next major version. Use `Input` with `type="search"` in a `Field` instead, or `Suggestion` if you need a clear button.

```tsx
import {
  Button,
  EXPERIMENTAL_Suggestion as Suggestion,
  Field,
  Input,
  Label,
} from '@digdir/designsystemet-react';

// Search field
<Field>
  <Label>Search</Label>
  <Input type="search" />
</Field>

// With clear button and search button
<Suggestion>
  <Suggestion.Input type="search" aria-label="Search" />
  <Suggestion.Clear />
  <Button type="submit">Search</Button>
</Suggestion>
```
