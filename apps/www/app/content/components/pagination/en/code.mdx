## Usage

Add the class name `ds-pagination` to the `<ds-pagination>` element.
The web component automatically fills the buttons or anchors based on the data attributes `data-current` and `data-total`.

If you wish to use your own buttons, you can add `<a>` or `<button>` elements inside `<ds-pagination>`. If you fill these with text and do not pass any attributes, the web component will not change the buttons.

## The `pagination` helper

`pagination` is a plain function that calculates which steps to show. It has no dependencies on the DOM or any framework, so you can use it in React, Vue, Svelte, on the server or in plain JavaScript. You render the elements yourself, and the function tells you what each element should contain.

```ts
import { pagination } from '@digdir/designsystemet-web';
// or from '@digdir/designsystemet-react' if you already use the React package

const { prev, next, pages } = pagination({ current: 5, total: 10, show: 7 });
```

### Input

| Option    | Type     | Default | Description                                                         |
| --------- | -------- | ------- | ------------------------------------------------------------------- |
| `current` | `number` | `1`     | The current page number                                             |
| `total`   | `number` | `10`    | The total number of pages                                           |
| `show`    | `number` | `7`     | The maximum number of steps to show, including ellipsis             |

### Output

The function returns an object with `prev`, `next` and `pages`. Each of these describe one element in the pagination:

| Key     | Element                        | Content                                                                          |
| ------- | ------------------------------ | -------------------------------------------------------------------------------- |
| `prev`  | The previous button            | `value` is the previous page number. `inert` is `true` when you are on the first page |
| `next`  | The next button                | `value` is the next page number. `inert` is `true` when you are on the last page      |
| `pages` | One list item per array entry  | `value` is the page number.<br />`inert` is `true` for an ellipsis<br />`aria-current` is `page` for the current page |


Properties that do not apply are `undefined`, so you can spread a step directly onto an element in frameworks such as React. The example above returns:

```ts
{
  prev: { value: 4 },
  next: { value: 6 },
  pages: [
    { value: 1 },
    { value: 0, inert: true }, // Ellipsis
    { value: 4 },
    { value: 5, 'aria-current': 'page' },
    { value: 6 },
    { value: 0, inert: true }, // Ellipsis
    { value: 10 },
  ],
}
```
