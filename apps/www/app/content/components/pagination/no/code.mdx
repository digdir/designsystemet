## Bruk

Legg klassenavnet `ds-pagination` på `<ds-pagination>`-elementet.
Webkomponenten fyller automatisk knappene med tekst basert på attributtene `data-current` og `data-total`.

Dersom du ønsker å lage dine egne knapper kan du legge inn `<a>` eller `<button>`-elementer inni `<ds-pagination>`. Dersom du fyller disse med tekst, og ikke sender noen attributter, vil ikke webkomponenten endre på knappene.

## Hjelpefunksjonen `pagination`

`pagination` er en ren funksjon som regner ut hvilke steg som skal vises. Den er ikke avhengig av DOM eller noe rammeverk, så du kan bruke den i React, Vue, Svelte, på serveren eller i ren JavaScript. Du tegner ut elementene selv, og funksjonen forteller deg hva hvert element skal inneholde.

```ts
import { pagination } from '@digdir/designsystemet-web';
// eller fra '@digdir/designsystemet-react' om du allerede bruker React-pakken

const { prev, next, pages } = pagination({ current: 5, total: 10, show: 7 });
```

### Input

| Valg      | Type     | Standard | Beskrivelse                                                  |
| --------- | -------- | -------- | ------------------------------------------------------------ |
| `current` | `number` | `1`      | Nummeret på gjeldende side                                   |
| `total`   | `number` | `10`     | Totalt antall sider                                          |
| `show`    | `number` | `7`      | Maks antall steg som skal vises, inkludert ellipser          |

### Output

Funksjonen returnerer et objekt med `prev`, `next` og `pages`. Hver av disse beskriver ett element i pagineringen:

| Nøkkel  | Element                           | Innhold                                                                        |
| ------- | --------------------------------- | ------------------------------------------------------------------------------ |
| `prev`  | Forrige-knappen                   | `value` er forrige sidenummer. `inert` er `true` når du er på første side      |
| `next`  | Neste-knappen                     | `value` er neste sidenummer. `inert` er `true` når du er på siste side         |
| `pages` | Ett objekt per pagineringssteg | `value` er sidenummeret.<br />`inert` er `true` for en ellipse. <br />`aria-current` er `page` for gjeldende side |

Egenskaper som ikke gjelder er `undefined`, så du kan spre et steg direkte på et element i rammeverk som React. Eksempelet over returnerer:

```ts
{
  prev: { value: 4 },
  next: { value: 6 },
  pages: [
    { value: 1 },
    { value: 0, inert: true }, // Ellipse
    { value: 4 },
    { value: 5, 'aria-current': 'page' },
    { value: 6 },
    { value: 0, inert: true }, // Ellipse
    { value: 10 },
  ],
}
```
