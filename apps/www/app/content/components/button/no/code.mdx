## Bruk
Klassenavnet `ds-button` blir satt på `<button>`.

Det er tre data-attributtar du kan bruke for tilpasning:
- `data-icon` - legg på dersom knappen kun har ikon.
- `data-variant` - set variant på knappen (`primary`, `secondary`, `tertiary`).
- `data-fullwidth` - legg på dersom knappen skal vere full bredde.

## CSS variablar og data-attributtar
Størrelsar styrast med [`data-size`](/no/fundamentals/code/sizes) og fargar med [`data-color`](/no/fundamentals/code/colors). Komponenten vil arve næraste forelder med desse satt.

## Eksempel

### Varianter

`data-variant` brukast for å endre utsjånad på knappen.

### Ikon

Dersom du kun har ikon i knappen kan du sette `data-icon="true"` for å få den firkanta.
Har du anna innhald, som tekst, vil knappen automatisk få luft rundt ikonet.

<Story story="Icons" />

### Knappar som lastar 
Dersom du skal ha ein knapp som lastar, set du `aria-busy="true"`. Laste-indikatoren blir då teikna i CSS, så du treng ikkje legge til ein sjølv. Dersom knappen berre inneheld eit ikon, blir ikonet skjult medan han lastar.

Merk: `aria-busy` hindrar ikkje at knappen utløyser interaksjonar. Den påverkar berre utsjånad og tilgjengelegheit, ikkje funksjonaliteten.
Dersom knappen ikkje skal kunne utføre handlingar, må du sjølv legge inn logikk som hindrar at callback-funksjonen blir køyrd.

## Knappar som er deaktivert

Så godt det lar seg gjerde burde ein [unngå deaktiverte knappar](/no/components/docs/button/accessibility#unngå-å-bruke-deaktiverte-knappar).
Dersom du har ein `<button>`, kan du deaktivere med attributten `disabled`. Dersom du har ein `<a>`, kan du deaktivere med attributten `aria-disabled="true"`.
Merk: `aria-disabled` hindrar ikkje at knappen utløyser interaksjonar. Den påverkar berre utsjånad og tilgjengelegheit, ikkje funksjonaliteten.
Dersom knappen ikkje skal kunne utføre handlingar, må du sjølv legge inn logikk som hindrar at callback-funksjonen blir køyrd.

## React
I React legg me også på `type="button"` som standard, for å unngå uventa submit i skjema.

```tsx
import { Button } from '@digdir/designsystemet-react';

<Button>Knapp</Button>;
```

### Ekstra logikk for knappar som lastar

I React brukar me `aria-busy={true}` for å vise at knappen lastar noko. Laste-indikatoren blir teikna i CSS, så du treng ikkje legge til ein sjølv. For å byte ut grafikken, set `--dsc-button-loading-icon-url`.

<Story story="Loading" language="react"/>

`loading`-propen fungerer framleis, men er utfasa til fordel for `aria-busy`.

### Knapp som lenkje

Lenker kan få utsjånad som ein knapp, men vurder først om det er betre å bruke [`Link`](/no/components/docs/link/overview)-komponenten. For å endre knappen til ei lenkje brukast `asChild`. Les meir om [komposisjon i Designsystemet](/no/fundamentals/code/composition).
