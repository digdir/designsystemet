## Usage
If you are using `@digdir/designsystemet-web`, you can implement toggle group by using the `data-toggle-group` attribute.

```html
<fieldset class="ds-toggle-group" focusgroup="radiogroup" aria-label="Text alignment" data-variant="secondary">
  <label class="ds-button">
    <input type="radio" name="alignment-two" value="left" checked />
    Leftadjusted
  </label>
  <label class="ds-button">
    <input type="radio" name="alignment-two" value="center" />
    Centered
  </label>
  <label class="ds-button">
    <input type="radio" name="alignment-two" value="right" />
    Rightadjusted
  </label>
</fieldset>
```

### Automatic versus manual activation

Toggle group supports two activation modes:

- **Automatic:** Options are activated immediately when the user navigates with the arrow keys, and each option is coded with `<label><input type="radio">`
- **Manual:** Options are activated only by pressing `Enter` or `Space`, and each option is coded with `<button role="radio" aria-checked="true | false">`

Automatic activation is the default in React and is recommended in most cases, while manual activation may be better when selecting an option triggers larger operations.

## React

```tsx
import { ToggleGroup } from '@digdir/designsystemet-react';

<ToggleGroup data-toggle-group='Options' defaultValue="option1">
  <ToggleGroup.Item value="option1">Option 1</ToggleGroup.Item>
  <ToggleGroup.Item value="option2">Option 2</ToggleGroup.Item>
</ToggleGroup>
```
