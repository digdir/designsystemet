## Bruk
Bruker du `@digdir/designsystemet-web` kan du implementere toggle group ved å bruke `focusgroup="radiogroup"` sammen med `aria-label`.
Merk at `focusgroup` er en [kommende W3C standard](https://open-ui.org/components/scoped-focusgroup.explainer/), foreløpig kun støttet i Chrome. Designsystemet legger automatisk til polyfill for støtte i alle nettlesere.

```html
<fieldset class="ds-toggle-group" focusgroup="radiogroup" aria-label="Tekstjustering" data-variant="secondary">
  <label class="ds-button">
    <input type="radio" name="alignment" value="left" checked />
    Venstestilt
  </label>
  <label class="ds-button">
    <input type="radio" name="alignment" value="center" />
    Midtstilt
  </label>
  <label class="ds-button">
    <input type="radio" name="alignment" value="right" />
    Høyrestilt
  </label>
</fieldset>
```

### Gammel måte med `<button>`
**Her må du håndtere tastaturnavigasjon og ARIA-roller sjølv.**
Du kan lese om kva du må gjere for å implementere dette i [tilgjengelighetsdokumentasjonen](/no/components/docs/toggle-group/accessibility).
Kvar knapp i gruppa er ein `<button>` med klassenavn `ds-button` med `aria-checked` som indikerer om knappen er vald eller ikkje.

```html
<div class="ds-toggle-group" focusgroup="radiogroup" aria-label="Filter" data-variant="primary">
  <button
    class="ds-button"
    type="button"
    id="togglegroup-item-1"
    aria-checked="true"
  >Innboks</button>
  <button
    class="ds-button"
    type="button"
    id="togglegroup-item-2"
    aria-checked="false"
  >Sendt</button>
</div>
```
