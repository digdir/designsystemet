## Bruk
Bruker du `@digdir/designsystemet-web` kan du implementere toggle group ved å bruke `focusgroup="radiogroup"` sammen med `aria-label`.

```html
<fieldset class="ds-toggle-group" focusgroup="radiogroup" aria-label="Tekstjustering" data-variant="secondary">
  <button type="button" class="ds-button" role="radio" aria-checked="true">
    Venstestilt
  </button>
  <button type="button" class="ds-button" role="radio" aria-checked="false">
    Midtstilt
  </button>
  <button type="button" class="ds-button" role="radio" aria-checked="false">
    Høyrestilt
  </button>
</fieldset>
```

### Automatisk versus manuell aktivering

Toggle group støtter to aktiveringsmoduser:

- **Automatisk:** Valg aktiveres umiddelbart når brukeren navigerer med piltastene, og hvert valg kodes med `<label><input type="radio">`
- **Manuell:** Valg aktiveres først ved `Enter` eller `Mellomrom`, og hvert valg kodes med `<button role="radio" aria-checked="true | false">`

Automatisk aktivering er standard i React og anbefales i de fleste tilfeller, mens manuell kan være bedre når et valg utløser større operasjoner.
