## Bruk
Bruker du `@digdir/designsystemet-web` kan du implementere toggle group ved å bruke `focusgroup="radiogroup"` sammen med `aria-label`.

```html
<fieldset class="ds-toggle-group" focusgroup="radiogroup" aria-label="Tekstjustering" data-variant="secondary">
  <button type="button" class="ds-button" role="radio" aria-checked="true">
    Venstestilt
  </button>
  <button type="button" class="ds-button" role="radio" aria-checked="false">
    Midtstilt
  </button>
  <button type="button" class="ds-button" role="radio" aria-checked="false">
    Høyrestilt
  </button>
</fieldset>
```

### Automatisk versus manuell aktivering
Toggle group støtter to aktiveringsmoduser: automatisk (med `<label><input type="radio">`) og manuell (med `<button role="radio" aria-checked="true | false">`).
Ved bruk av `<label><input type="radio">` aktiveres valg med én gang brukeren navigerer med piltastene, mens med `<button>` må aktiveres valg først ved Enter eller Mellomrom. 
Automatisk aktivering er standard i React og anbefalt, men manuell kan være nyttig dersom toggle group utløser større operasjoner, som å bytte mellom liste- og kartvisning eller gjøre nye API-kall.
