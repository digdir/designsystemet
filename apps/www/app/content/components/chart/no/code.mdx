## Bruk

Legg klassen `ds-chart` på et `<ds-chart>`-element som inneholder en `<table>`.
Webkomponenten leser tallene i tabellen og sender dem videre til CSS-en som custom properties. Den legger ikke til eller fjerner elementer, og CSS-en står for all tegningen.

```html
<ds-chart class="ds-chart" data-variant="column">
  <table class="ds-table">
    <caption>Søknader per år</caption>
    <thead>
      <tr><th>År</th><th>Innvilget</th><th>Avslått</th></tr>
    </thead>
    <tbody>
      <tr><th scope="row">2024</th><td>1 310</td><td>420</td></tr>
      <tr><th scope="row">2025</th><td>1 720</td><td>380</td></tr>
    </tbody>
  </table>
</ds-chart>
```

- Den første kolonnen er kategorien. Bruk `<th scope="row">`.
- Hver av de neste kolonnene er en serie, og `<thead>` brukes som forklaring.
- `<caption>` er tittelen på diagrammet.
- Fram til JavaScript er lastet, vises tabellen som en vanlig tabell.

Bruk `data-variant` for å velge mellom `column`, `bar`, `line` og `table`. `table` viser tabellen slik den er.

### Tall
Tallene leses fra teksten i hver `<td>`, basert på nærmeste `lang`-attributt. Det betyr at `1 234,5` forstås på norsk og `1,234.5` på engelsk, og at enheter som `kr` og `%` ignoreres.

Bruk `data-value` hvis teksten ikke er et rent tall:

```html
<td data-value="1500000">1,5 millioner</td>
```

Celler uten tall hoppes over.

### Akse
Aksen regnes ut fra tallene, rundes av til lettleste verdier og inkluderer alltid null. Bruk `data-min` og `data-max` på `<ds-chart>` for å utvide aksen, for eksempel for å gi flere diagrammer samme skala.

### Bytt mellom diagram og tabell
Radioknapper og select med `data-chart="variant"` oppdaterer `data-variant` med verdien sin. Attributtet kan også settes på et foreldreelement, som `<fieldset>` i en [toggle group](/no/components/docs/toggle-group/code).

```html
<ds-chart class="ds-chart" data-variant="column">
  <fieldset class="ds-toggle-group" focusgroup="radiogroup" aria-label="Visning" data-chart="variant">
    <label class="ds-button"><input type="radio" name="view" value="column" checked />Diagram</label>
    <label class="ds-button"><input type="radio" name="view" value="table" />Tabell</label>
  </fieldset>
  <table class="ds-table">...</table>
</ds-chart>
```

Du kan også endre `data-variant` selv.

## CSS-variabler og data-attributter

Farger styres med [data-color](/no/fundamentals/code/colors). Hver serie har sin egen `--dsc-chart-color-*`, `--dsc-chart-pattern-*` (brukes på søyler og stolper) og `--dsc-chart-shape-*` (brukes på punkter i linjer). Standardfargene bruker kun gjeldende farge, siden temaer ikke har de samme fargenavnene, så overstyr dem hvis du vil bruke mer av temaet ditt:

```css
.ds-chart {
  --dsc-chart-color-2: var(--ds-color-brand1-base-default);
  --dsc-chart-pattern-3: none;
  --dsc-chart-size: 20rem;
}
```

Pass på at seriene fortsatt kan skilles fra hverandre uten farge hvis du fjerner et mønster.

### Tegn ditt eget diagram
`<ds-chart>` setter følgende custom properties, som du kan bruke til å tegne andre diagramtyper med din egen CSS. Alle verdier på `<td>` er mellom `0` og `1`.

| Element | Property | Beskrivelse |
|---|---|---|
| `<ds-chart>` | `--_ds-chart-axis` | Tekstene på aksen som en streng, fra høyest til lavest |
| `<ds-chart>` | `--_ds-chart-steps` | Antall steg på aksen |
| `<ds-chart>` | `--_ds-chart-series` | Antall serier |
| `<ds-chart>` | `--_ds-chart-zero` | Hvor null er på aksen |
| `<td>` | `--_ds-chart-value` | Hvor verdien er på aksen |
| `<td>` | `--_ds-chart-from` og `--_ds-chart-to` | Hvor søylen eller stolpen starter og slutter, også når den er stablet |
| `<td>` | `--_ds-chart-next` | Verdien til neste rad i samme serie, brukes til å tegne linjer |

Hvis du ikke vil bruke JavaScript, kan du sette de samme verdiene på serveren og bruke `<div class="ds-chart">`. Logikken for skalaen er eksportert for å hjelpe med dette:

```ts
import { chartScale } from '@digdir/designsystemet-web';

chartScale(0, 1720); // { min: 0, max: 2000, step: 500, ticks: [2000, 1500, 1000, 500, 0] }
```

## React

`Chart` rendrer kun `<ds-chart>`, og brukes sammen med [Table](/no/components/docs/table/code).

```tsx
import { EXPERIMENTAL_Chart as Chart, Table } from '@digdir/designsystemet-react';

<Chart data-variant='column'>
  <Table>
    <caption>Søknader per år</caption>
    <Table.Head>
      <Table.Row>
        <Table.HeaderCell>År</Table.HeaderCell>
        <Table.HeaderCell>Innvilget</Table.HeaderCell>
      </Table.Row>
    </Table.Head>
    <Table.Body>
      <Table.Row>
        <Table.HeaderCell scope='row'>2025</Table.HeaderCell>
        <Table.Cell>1 720</Table.Cell>
      </Table.Row>
    </Table.Body>
  </Table>
</Chart>
```
