## Usage

You can use Dropdown in plain HTML by using the `popover` attribute on an element with the class `ds-dropdown`, and connecting it to a trigger with `popovertarget="ID-OF-DROPDOWN-HERE"`.
Designsystemet automatically adds [popover-polyfill (npmjs.com)](https://www.npmjs.com/package/@oddbird/popover-polyfill) to support the native [Popover API (mozilla.org)](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API/Using) in older browsers if needed.

You can control positioning with attributes on the dropdown itself:
| attribute     | type   | default    |
|---------------|--------|------------|
| data-placement | `'top' \| 'top-start' \| 'top-end' \| 'right' \| 'right-start' \| 'right-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'left' \| 'left-start' \| 'left-end' \| 'none'` | `'bottom'` |
| data-overscroll | `'contain' \| undefined` | `undefined` |
| data-autoplacement | `boolean` | `true` |

## React

```jsx
<Button popovertarget='dropdown'>Dropdown</Button>
<Dropdown id='dropdown'>
    <Dropdown.List>
        <Dropdown.Item>
        <Dropdown.Button>Item 1</Dropdown.Button>
        </Dropdown.Item>
        <Dropdown.Item>
        <Dropdown.Button>Item 2</Dropdown.Button>
        </Dropdown.Item>
    </Dropdown.List>
</Dropdown>
```

### `popovertarget`

When you use `popover` without `Dropdown.TriggerContext`, you link yourself trigger and `popover`.
Then `popovertarget` is used in lowercase, so that all versions of React correctly render the attribute.
When using `@digdir/designsystemet-react` we extend `@types/react-dom` to accept this.


### Without `TriggerContext`

`Dropdown` uses the popover API, so you can use `Dropdown` without `Dropdown.Trigger`.

You must then add `popovertarget={id}` to `Dropdown`, and `id` to `Dropdown`.

### Controlled

If you submit `open`, then you use `Dropdown` controlled. You can use `onClose` to get notified when `Dropdown` wants to close.

Note that we do not use `onClick` on the trigger, the dropdown handles this internally and sends to `onOpen` and `onClose`.
