## Bruk
Details er en native `<details>`-tagg.

### Med ramme

Ønsker du å ha en ramme rundt kan du putte den i en `ds-card`.
```
<div class="ds-card">
  <details class="ds-details">…</details>
</div>
```

## CSS variabler og data-attributter
Størrelsar styrast med [data-size](/no/fundamentals/code/sizes) og fargar med [data-color](/no/fundamentals/code/colors).

## Polyfill
Vi bruker [@u-elements/u-details/polyfill](https://u-elements.github.io/u-elements/elements/u-details) får korrigere manglende opplesing av tilstand `<summary>` i Firefox med Android TalkBack skjermlesar.

## React

```tsx
/* Utan ramme */
import { Details } from '@digdir/designsystemet-react';

<Details>
  <Details.Summary>Details heading text</Details.Summary>
  <Details.Content>Details content</Details.Content>
</Details>

/* Med ramme */

import { Details, Card } from '@digdir/designsystemet-react';

<Card>
  <Details>
    <Details.Summary>Details heading text</Details.Summary>
    <Details.Content>Details content</Details.Content>
  </Details>
</Card>
```
