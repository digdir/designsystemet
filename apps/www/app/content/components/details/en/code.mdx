## Usage
Details is a native `<details>` element.

### With frame

If you want a frame around details, you can put it in a `ds-card`.
```
<div class="ds-card">
  <details class="ds-details">...</details>
</div>
```

## CSS variables and data attributes
Sizes are controlled with [data-size](/en/fundamentals/code/sizes) and colors with [data-color](/en/fundamentals/code/colors). 
The component will inherit from the closest parent where these are set.

## Polyfill
In Firefox, we automatically add accessibility attributes to `<summary>`, so the TalkBack screen reader on Android announces state and role correctly.

## React

```tsx
/* Without frame */
import { Details } from '@digdir/designsystemet-react';

<Details>
  <Details.Summary>Details heading text</Details.Summary>
  <Details.Content>Details content</Details.Content>
</Details>

/* With frame */

import { Details, Card } from '@digdir/designsystemet-react';

<Card>
  <Details>
    <Details.Summary>Details heading text</Details.Summary>
    <Details.Content>Details content</Details.Content>
  </Details>
</Card>
```
