For the details component, we use [u-details (github.io)](https://u-elements.github.io/u-elements/elements/u-details), which builds on the semantic HTML elements `<details>` and `<summary>`.
</Alert>

## Keyboard navigation
Keyboard navigation is handled by Designsystemet. Note that if you use `event.preventDefault()` on a keypress event, you prevent the browser's default behaviour. In that case, you need to test keyboard navigation yourself.

## Handled by Designsystemet
- The component uses native `<details>` and `<summary>`, so the open and closed state is communicated to assistive technology.
