## Usage

Avatar uses the class name `ds-avatar` on a `<span>` with `role="img"`.Ensure the avatar has an [accessible name](/en/components/docs/avatar/accessibility).

## CSS variables and data attributes

Sizes are controlled with [`data-size`](/en/fundamentals/code/sizes) and colors with [`data-color`](/en/fundamentals/code/colors). The component will inherit from the closest parent where these are set.

### With image or icon
Avatar displays a user icon by default, but this can be overridden in CSS using the `--dsc-avatar-icon-url` variable. 

If you add an image or icon as content inside the avatar, make sure to set `aria-hidden="true"` to avoid duplicate information. You must add an `aria-label` to the avatar yourself to explain who or what the avatar represents.

<Story story="WithImageAndIcon" />

### Shape and radius

Use `--dsc-avatar-radius` CSS custom property to adjust the radius of the avatar.

## React

```tsx
/* With default user icon */
<Avatar aria-label="Ola Nordmann" />

/* With initials */
<Avatar aria-label="Ola Nordmann">ON</Avatar>

/* With image */
<Avatar aria-label="Ola Nordmann">
  <img src="..." />
</Avatar>
```
