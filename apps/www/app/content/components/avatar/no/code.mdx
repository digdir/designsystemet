## Bruk

Avatar bruker klassenavnet `ds-avatar` på en `<span>` med `role="img"`. Sørg for at avatar har [tilgjengelig navn](/no/components/docs/avatar/accessibility).

## CSS variabler og data-attributter
Størrelser styres med [`data-size`](/no/fundamentals/code/sizes) og farger med [`data-color`](/no/fundamentals/code/colors). Komponenten vil arve nærmeste forelder med disse satt.

## Eksempel

### Med initialer

Legg tekst inn i avatar for å vise initialer.

<Story story="Initials" />

### Med bilde eller ikon
Avatar viser som standard et brukerikon, men dette kan overstyres i CSS med variabelen `--dsc-avatar-icon-url`. 

Dersom du legger bilder eller ikon som barn må du sørge for å sette `aria-hidden="true"` for å unngå dobbel informasjon. Du må selv sette `aria-label` på avatar for å forklare hvem eller hva avataren representerer.

<Story story="WithImageAndIcon" />

### Form og avrunding

Du kan bruke `--dsc-avatar-radius` CSS custom property for å tilpasse avrundingen på avatar. 

<Story story="Radius" />

## React

```tsx
/* Med standard brukerikon */
<Avatar aria-label="Ola Nordmann" />

/* Med initialer */
<Avatar aria-label="Ola Nordmann">ON</Avatar>

/* Med bilde */
<Avatar aria-label="Ola Nordmann">
  <img src="..." />
</Avatar>
```
